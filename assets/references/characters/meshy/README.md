# Character modeling handoff

- `mathieu-a-pose.png`: Mathieu, olive overshirt, charcoal T-shirt, jeans and brown boots.
- `orderly-a-pose.png`: Man in White, aged ivory uniform, short dark hair and visible face.

Each PNG contains one full-body front view with arms separated from the torso, intended as a separate Meshy image input. The original three-view sheets one directory above remain additional identity/costume references. Both outputs are 1024 x 1536 pixels.

Generated using the built-in imagegen tool from the user-supplied reference sheets. Exact generation prompts are in `prompts.md`. User selected these sheets over the older patient-clothing/featureless-face descriptions. The user will handle Meshy model creation and Mixamo rigging/animation, then return the resulting assets for game integration.

These are modeling inputs, not completed 3D assets. The rejected procedural/free-base character experiment was not integrated into either runtime character scene.
